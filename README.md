# play.zevkev.de

Website des ZEVKEV-Minecraft-Servers (GitHub Pages, eigene Domain play.zevkev.de).

- `index.html` – One-Pager mit Live-Status (api.mcstatus.io), Features, Regeln, Discord
- `map/` – leitet zur Live-Karte (squaremap auf dem Spielserver, http://map.zevkev.de:17165)
- Design: ZevKev-Designsystem wie zevkev.de (Papier, Tape, Schneidematte), Schrift Bebas Neue selbst gehostet
